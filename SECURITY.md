# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly:

1. **Do not** open a public GitHub issue
2. Email [mdag.92988@protonmail.com](mailto:mdag.92988@protonmail.com) with details
3. Include steps to reproduce if possible

You should receive a response within 48 hours.

## Scope

Security issues in the following areas are in scope:

- Core implementation bugs
- Key derivation, encryption, or sensitive data handling (if applicable)
- Memory handling of sensitive data (e.g. zeroization)
- File permission issues
- Dependency vulnerabilities
